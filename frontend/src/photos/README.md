# Local dish photos (not committed)

Put square WebP (or JPG/PNG) photos here, named after the dish in lower case with hyphens,
for example `dal-makhani.webp` or `masala-dosa.webp`. The app shows a photo when
one exists for a dish, and its drawing when not.

Everything in this folder except this README is ignored by git. Only commit
photos you took yourself or that have a licence allowing it.
